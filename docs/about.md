# About

Pre-computed embedding vectors for every half-verse of the Hebrew
psalms: 15 Hebrew and multilingual embedding models, split across 4
Hebrew BERT-family models, 7 open-weight multilingual encoders, and 4
embedding APIs (Gemini, OpenAI, Cohere, Voyage).

Part of [tehillim](https://github.com/rdtaylorjr/tehillim), a
computational analysis of the Hebrew psalms.

Uses BHSA's `half_verse` (colon) node numbering. Built and tested
against BHSA version `2021`.

Generation code is in `programs/`.
